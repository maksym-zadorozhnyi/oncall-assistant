## Що виправлено після цього діалогу

| Що в діалозі | Виправлення |
|---|---|
| подвійний «Дивився» (№ 2, 3, 4) | код вирізає з тексту LLM рядки «Дивився:», «Момент:», «⚠ …»; в історії службовий рядок — «[система: дивився …]»; правило 19 |
| «журнал не показує причини» (№ 5) | правило 17: не стверджувати, що даних немає, якщо їх не запитували |
| «можу перевірити…» (№ 1–6) | правило 16 |
| «Якщо хочеш» (№ 6) | правило 20: на «ви» |
| `/moment 2026-18-11 22:00` — помилка формату | `/moment` приймає ще «18.11.2026 22:00» і «18.11 22:00» |

Кількість шумових записів (№ 6) — помилка переказу, окремого виправлення немає;
ловитиме іспит.
